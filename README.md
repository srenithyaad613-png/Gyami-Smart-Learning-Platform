# Gyami Smart Learning Platform

A beginner-friendly smart education platform built with FastAPI, SQLite, HTML, CSS and JavaScript.

## Features
- Student signup and login
- Personal dashboard
- Course progress tracking
- Assignments and task completion
- Notes with persistent storage
- Focus timer and focus-session history
- Smart quiz with score tracking
- AI study assistant
- Digital books/resources
- Progress analytics
- Study streak
- Achievements
- Notifications
- Daily study recommendation
- Responsive futuristic UI

## Run locally
```bash
pip install -r requirements.txt
python -m uvicorn main:app --reload
```

Open:
http://127.0.0.1:8000

The database is created automatically on first run.
